# VKhelper

VKhelper — MVP AI-ассистента педагога для сообщений сообщества VK. Он получает сообщения через VK Long Poll, хранит отдельную историю диалога и заявки в SQLite, использует Gemini API для понимания естественного языка и отвечает только проверенными бизнес-данными.

## Быстрый запуск

Требуется Python 3.11+; внешние пакеты не нужны.

1. Скопируйте `.env.example` в `.env` и внесите значения.
2. Отредактируйте `data/business.json` и `data/knowledge.md`.
3. Запустите:

```bash
python3 -m src.main
```

Перед первым запуском в настройках сообщества VK включите сообщения сообщества и Long Poll API, а в Long Poll включите событие `message_new`. Токен сообщества поместите в `VK_GROUP_TOKEN`, числовой ID сообщества — в `VK_GROUP_ID`.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `AI_PROVIDER` | Сейчас поддерживается `gemini`. |
| `GEMINI_API_KEY` | API-ключ Gemini. Создайте его в [Google AI Studio](https://aistudio.google.com/app/apikey). |
| `GEMINI_MODEL` | Модель Gemini, например `gemini-3.5-flash`. |
| `VK_GROUP_TOKEN`, `VK_GROUP_ID` | Токен и ID сообщества VK. |
| `DATABASE_PATH` | Путь к SQLite; на хостинге укажите постоянный каталог. |
| `MANAGER_VK_ID`, `MANAGER_VK_URL` | Получатель уведомлений и/или прямая ссылка на руководителя. |

`.env` и SQLite-файлы исключены из Git. Никогда не добавляйте ключи и токены в репозиторий.

## Данные, которые заполняете вы

- Цена, адрес, график, статус набора и сведения руководителя — [data/business.json](data/business.json).
- Текстовая база знаний об обучении — [data/knowledge.md](data/knowledge.md).

Если точного значения нет, оставьте пустую строку: бот не станет его придумывать и предложит уточнить у руководителя. Стоимость месяца рассчитывается кодом из цены занятия и количества занятий, а не моделью.

## Как это работает

Для каждого `vk_user_id` хранится до 10 последних пар сообщений, которые передаются Gemini как контекст. Gemini возвращает валидируемый JSON: intent, извлечённые данные ребёнка/родителя и черновой ответ. Код самостоятельно выдаёт фактические ответы, создаёт lead, проверяет явное согласие и только после него отправляет руководителю уведомление через VK.

При сбое Gemini фактические вопросы и базовый сценарий записи продолжают обрабатываться безопасным fallback. Повторное VK-событие игнорируется по `peer_id:conversation_message_id`.

## Развёртывание

На BotHost или похожем сервисе задайте все переменные окружения в панели, установите `DATABASE_PATH` в предоставленный persistent storage и используйте команду запуска `python3 -m src.main`. Приложение не привязано к конкретному хостингу.
